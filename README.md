# Mirage

Bienvenue sur mon projet Mirage !

C'est mon premier dépôt GitHub, et le point de départ de mon apprentissage du
développement web — avec un objectif final : savoir construire des **SaaS
d'automatisation** (des outils qui connectent des applications entre elles et
exécutent des workflows automatiquement, comme Zapier, Make ou n8n).

## Contenu du dépôt

- `index.html`, `css/style.css`, `js/script.js` — un site vitrine simple,
  qui me sert de terrain d'entraînement pratique pour chaque notion apprise.
- [`docs/ROADMAP.md`](docs/ROADMAP.md) — le parcours d'apprentissage complet,
  des bases du web jusqu'à la construction d'un SaaS d'automatisation.
- [`docs/GLOSSAIRE.md`](docs/GLOSSAIRE.md) — un glossaire A-Z de tout le
  jargon dev/SaaS/automatisation, à consulter dès qu'un mot m'échappe.

## Pour voir le site en local

Ouvre simplement `index.html` dans un navigateur, ou lance un petit serveur
local (par exemple avec l'extension "Live Server" de VS Code).
